CRUD API
A simple CRUD API built with Node.js and TypeScript.

🚀 Setup and Running
1. Clone this repository, checkout into develop
2. Environment Variables
Create a .env file in the root of the project and set:
PORT=4001
3. Running the app
 npm run start:dev
 saves users src/db.json
4. Build
 npm run start:prod
5. Running tests
 npm run test
